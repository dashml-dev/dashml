The Problem

❌ Traditional Approach

  • ✗ Write dashboard in Streamlit
  • ✗ Rewrite for Plotly embed
  • ✗ Rewrite again for Observable
  • ✗ Manually recreate in Superset
  • ✗ Different APIs, different paradigms
  • ✗ No single source of truth

✅ DashML Approach

  • ✓ Define dashboard once in YAML
  • ✓ Compile to any platform
  • ✓ Same spec → Streamlit, Plotly, Observable
  • ✓ Direct API creation in Superset
  • ✓ One language, consistent experience
  • ✓ Version-controlled dashboard definitions
2 / 12

Philosophy

  • ◆ Write once, deploy anywhere
    Single spec generates code for multiple platforms
  • ◆ No runtime dependencies
    Generated code is standalone and self-contained
  • ◆ Build-time compilation
    DashML is a compiler, not a runtime framework
  • ◆ Hexagonal architecture
    Clean separation between core engine and transformers
"DashML never materializes data — it only generates code that will load data at runtime."

Simple & Declarative

version: 0.1 title: "Sales Dashboard" style: "styles/dracula.dmls" data: type: csv path: "data/sales.csv" charts: - id: "sales_by_country" type: "bar" title: "Sales by Country" x: "country" y: "sales" agg: "sum"

Key Concepts

  • → version — Spec version for compatibility
  • → title — Dashboard title
  • → style — Theme file (.dmls)
  • → data — Data source (CSV, SQL, BigQuery)
  • → charts — Array of chart definitions

Command Line Interface

# Generate Streamlit app python -m dashml_new.cli build dashboard.dashml --target streamlit --output app.py # Generate Plotly HTML python -m dashml_new.cli build dashboard.dashml --target plotly --output dashboard.html # Generate Observable Plot python -m dashml_new.cli build dashboard.dashml --target observable --output viz.html # Create Superset dashboard directly python -m dashml_new.cli build dashboard.dashml --target superset \ --superset-user admin --superset-password admin # With SQL database python -m dashml_new.cli build sql.dashml --target plotly --output ./output \ --db-type postgresql --db-host localhost --db-name mydb # With BigQuery python -m dashml_new.cli build bigquery.dashml --target plotly --output ./output \ --bq-project my-gcp-project
